# Текущая стадия: DRAFT — сборка черновика ИПР

Собери черновик на 2–3 приоритета, опираясь на выявленные разрывы и интересы.

Для каждого приоритета:

- **goalCategory** — рубрика из справочника «Категории целей по развитию»,
  дословно одно из перечисленных там значений;
- **developmentGoal** — цель по SMART, с конкретной датой и измеримым результатом;
- **competencyCodes** — коды компетенций целевой роли из контекста ([COMP:...]);
- **actions** — 2–3 развивающих действия, то есть как именно сотрудник будет
  закрывать этот разрыв.

## Про действия

Это строки таблицы формы «ПЛАН РАЗВИТИЯ»: инструмент, конкретное действие, срок.

- Инструмент бери у активности из контекста — он там указан.
- Не ставь все действия на один инструмент: если сотрудник выбрал практику,
  основная часть должна быть «Развитие на рабочем месте», но курс или разбор
  с наставником обычно дополняют её, а не исключают.
- Сроки внутри приоритета разнеси: действия идут шагами.
- Действие должно быть проверяемым. «Изучить интеграции» — плохо;
  «описать и согласовать со смежной командой контракт интеграции» — хорошо.

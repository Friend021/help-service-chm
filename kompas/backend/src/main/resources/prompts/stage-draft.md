# Текущая стадия: DRAFT — сборка черновика ИПР

Собери черновик на 2–3 приоритета, опираясь на выявленные разрывы и интересы.

Для каждого приоритета:
- developmentGoal — по SMART, с конкретной датой и измеримым результатом;
- competencyCodes — коды компетенций целевой роли из контекста ([COMP:...]);
- activityCodes — коды активностей из каталога в контексте ([ACT:...]),
  подходящие под заявленный формат развития;
- milestones — 1–2 измеримые реперные точки со сроками.

В message коротко объясни логику приоритетов и спроси, что скорректировать.

# «Компас» — прототип сервиса формирования ИПР

Диалоговый помощник перед формой **«ПЛАН РАЗВИТИЯ»**: в диалоге с ИИ оценивает разрыв между
текущей и целевой должностью, собирает черновик индивидуального плана развития (цели,
развивающие действия, сроки) с заземлением на справочники (RAG) и возвращает план обратно в форму.

> **Это прототип / эталон поведения.** Данные синтетические. Боевую версию команда делает заново
> во внутреннем контуре — читать первым **[HANDOFF.md](HANDOFF.md)**, затем `docs/tech-task.md` (ТЗ).

## Запуск одной командой

Нужен только Docker.

```bash
cp .env.example .env          # по желанию: LLM_API_KEY для живого ИИ (без него — офлайн-мок)
docker compose up --build
```

Открыть **http://localhost:8081** → войти **demo / demo** → «Создать через Компас» → диалог
на :4200 → черновик → экспорт обратно. Поднимается весь актуальный стек: postgres + auth-mock
(Keycloak) + backend + legacy-stub + frontend-v2. Вариант без docker и разбор — в [HANDOFF.md](HANDOFF.md).

## Что где (актуальный стек)

- **`backend/`** — Spring Boot 3.3 / Java 21, PostgreSQL + Flyway. Актуальный слой —
  **`ru.cft.kompas.v1`** (контроллеры `/api/v1`, SSE, `V1DialogService`, Keycloak RS256).
- **`frontend-v2/`** — Angular 22 (signals): онбординг, опросник, черновик ИПР, экспорт.
- `legacy-stub/` — заглушка «ПЛАН РАЗВИТИЯ» (точка входа, :8081). `auth-mock/` — dev-мок Keycloak (:3000).
- `docs/` — документация (ТЗ, архитектура v1, сквозной процесс, контракт входа).

> ⚠️ В репозитории есть и **старый стек** (`frontend/` Angular 18, слой `/api/*`,
> `docker-compose.legacy-stack.yml`) — оставлен для совместимости и **для боевой не нужен**.
> Актуальное — `frontend-v2` + `ru.cft.kompas.v1`.

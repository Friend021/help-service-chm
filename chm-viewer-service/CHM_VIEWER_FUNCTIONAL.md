# CHM Help Viewer — функциональное описание

## Суть сервиса

Веб-сервис для хранения и просмотра справочной документации. Принимает файлы `.chm` (скомпилированная справка Windows), конвертирует их в веб-формат и отображает как удобный онлайн-справочник.

---

## Экраны и функциональность

### 1. Главная страница — библиотека книг

- Отображает список всех загруженных справочников в виде карточек
- Каждая карточка содержит: название книги, статус (READY / обработка), количество страниц, наличие оглавления
- Кнопка **Refresh** — обновить список (на случай новых загрузок)
- Кнопка **+ Upload** — перейти к загрузке нового файла

### 2. Страница загрузки

- Drag-and-drop зона для `.chm` файлов
- Очередь файлов с прогресс-баром загрузки каждого
- Статусы файла: Ожидание → Загрузка (%) → Готово / Ошибка
- После успешной загрузки — ссылка «Открыть viewer →»
- Кнопки: **Upload all**, **Clear done**

### 3. Просмотрщик документации (viewer)

- Двухпанельный интерфейс:
  - **Левая панель** — дерево оглавления (TOC) с разворачиваемыми разделами
  - **Правая панель** — содержимое выбранной страницы
- Навигация по клику на пункт оглавления
- Строка поиска по содержимому книги
- Хлебные крошки внутри страниц

---

## Пользовательские сценарии

| Сценарий | Действия |
|---|---|
| Загрузить новую справку | Upload → перетащить .chm → дождаться конвертации → открыть |
| Открыть справку из другого интерфейса | Прямая ссылка вида `/viewer.html?book=название` |
| Найти информацию | Открыть книгу → поиск по ключевому слову |
| Перейти к нужному разделу | Дерево оглавления слева |

---

## Технические ограничения (для понимания при проектировании)

- Конвертация занимает несколько секунд — нужен индикатор обработки
- Один `.chm` = одна «книга» в библиотеке
- Название книги берётся из имени файла

Getting Started

Follow these steps to get up and running quickly.

Step 1: Installation

Download the installer from the official website and run it with administrator privileges.

setup.exe /silent /install

Step 2: Configuration

Open the configuration file at config/settings.xml and adjust the parameters:

  • host — server address (default: localhost)
  • port — port number (default: 8080)
  • timeout — connection timeout in seconds

Step 3: First Launch

Start the application from the Start Menu or run:

app.exe --config config/settings.xml
